# Sample prescriptions (fake)

Invented doctors, numbers and patient. For demo and manual testing only.

Without a `GEMINI_API_KEY`, the backend's demo reader fills the review screen for these three files, matched by file name (`sore-throat`, `allergy`, `headache`). Any other file falls back to manual entry.

`headache.png` names Dr. A. Mehra with no phone or registration number, so uploading it after `sore-throat.png` shows the "Same doctor?" question.

# S4: Feedback and allergies
As a user I record what worked and what I am allergic to.

Acceptance criteria
- Given a medicine from a confirmed prescription, the user can mark worked / did not work / side effect, and change or clear it at any time. This is done on the prescription and on the "Feedback on past medicines" screen. Chat shows feedback but never asks for it.
- Allergies are added and removed on the profile screen (S10).
- Given an allergy added, then matching medicines are excluded from chat suggestions.
- Given invalid input (empty name, over-long text), then 400.

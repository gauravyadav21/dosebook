# Design assets

- `dosebook-logo.svg`: the logo on its rounded square, 108 x 108 grid. Source for the Android PNG icons.
- `figma-s11-frames.js`: a Figma plugin script that adds the logo sheet and three frames (Splash, Today as a visitor, Create account) to the `Screens` page of the design file. It was refused by the Figma plan's call limit on 5 Oct 2026 and has not been run. Run it once through the Figma MCP `use_figma` tool; it places the frames below the existing ones and numbers them after the highest existing frame.
